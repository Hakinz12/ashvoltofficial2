ASHVOLT Premium Website Starter
================================
Open index.html in a browser to preview (internet is used for Google Fonts).

Includes:
- Premium responsive Halloween/Web3 landing page
- Original user-provided ASHVOLT character artwork
- Cinematic village atmosphere, purple/gold/orange palette
- Mobile navigation, gentle animations, interactive Ghostie
- Character, movie, token, roadmap, whitepaper, community sections
- Risk disclaimer and reduced-motion support

Before publishing, replace placeholder buttons/links with verified official:
1. Pump.fun/token page and contract address/network
2. X and Telegram community links
3. Movie/video URL
4. Whitepaper and approved roadmap files/URLs

The roadmap copy is a draft based on the vision shared in chat; confirm it with the project owner. This frontend does not connect a wallet or perform transactions.

Deploy by uploading the extracted folder to Vercel, Netlify, or GitHub Pages. Keep index.html and assets/ together.
